## 说明

- 本仓库只收录**文档**（PDF / Word / 图片 / 文本），听力音频与视频未包含。
- 部分年份的真题在不同目录中重复收录，内容一致，任选其一即可。
- 资料来源于网络整理，仅供个人学习备考使用，请勿用于商业用途。

## 使用方式

- 在网页上直接点击文件即可预览或下载；
- 或克隆整个仓库：

```bash
git clone https://github.com/baiyaxs/CET-6.git
```

> Windows 下部分文件路径较长，克隆前可先执行 `git config --global core.longpaths true`。
